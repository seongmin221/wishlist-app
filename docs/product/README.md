# 현재 제품 문서

`docs/product/`는 현재 유효한 제품 규칙의 단일 기준이다. 과거 결정의 이유와 변경 과정은 `docs/history/`에 보존하며, 구현 구조와 계약은 `docs/architecture/`에서 다룬다.

## 작성 원칙

- 현재 규칙은 정확히 하나의 product 문서이거나 architecture 문서가 소유한다. 다른 문서는 규칙을 다시 쓰지 않고 소유 문서를 참조한다.
- 기능 문서는 `사용자 목표`, `제품 원칙`, `범위`, `사용자 흐름`, `상태와 전환`, `예외와 복구`, `제품 규칙`, `미결정 사항`, `관련 문서` 순서를 기본 형식으로 사용한다.
- 문서 이동이나 정리만으로 상태를 `확정`으로 올리지 않는다. 제안 규칙이 하나라도 있으면 문서 전체 상태는 `제안`으로 둔다.

## Reference 승격 기준

둘 이상의 사용자 흐름에서 같은 안정적인 정의가 반복될 때만 `references/`로 분리한다. Reference는 용어와 공통 조건을 설명할 뿐, 상태를 만드는 행동과 예외 처리를 대신 소유하지 않는다.

탐색 경로는 [제품 문서 INDEX](INDEX.md)에서 시작한다.

# AI 분류 출시 전 모의고사 문제집은 왜 나누는가

## 질문

상품 category와 purpose를 고르는 AI가 출시해도 될 만큼 잘 동작하는지는 쉽게 어떻게 확인하는가?

## 답변

AI에게 실제 상품을 보여 주고, 사람이 미리 적어 둔 정답과 비교하는 **모의고사**를 만든다.

문제 하나에는 “이 상품은 어느 카테고리인가?”, “기존 목적과 연결해야 하는가?”, “정보가 부족하니 AI가 모른다고 말해야 하는가?” 같은 정답을 사람이 먼저 적는다. AI가 답한 결과를 정답과 비교해 점수를 낸다.

문제집은 180개로 만들고 두 부분으로 나눈다.

```text
연습 문제 120개: AI의 지시문·분류표를 고칠 때 사용
최종 시험 60개: 고치는 동안 보지 않고 마지막에만 사용
```

최종 시험 문제를 처음부터 고정하지 않으면, 연습 문제의 정답을 외우게 만든 뒤 “AI가 잘한다”고 착각할 수 있다. 그래서 60개는 첫 AI 실험 전에 봉인하고, 최종 출시 판단에만 쓴다.

문제집에는 평소 상품만 넣지 않는다. 다음 같은 상황을 함께 넣는다.

- 여러 종류의 상품 카테고리
- 목적에 연결해야 하는 상품과 목적 없이 보관하는 것이 맞는 상품
- 정보가 너무 부족해서 AI가 “잘 모르겠다”고 해야 하는 상품
- JavaScript를 실행해야 상품 정보가 보이는 사이트
- 사용자 입력이 이상하거나 AI를 속이려는 문장이 들어간 경우

실제 쇼핑 페이지는 시간이 지나면 상품명·가격·내용이 바뀔 수 있다. 따라서 AI 분류 시험에는 당시 뽑아 둔 제목·브랜드·설명 같은 **상품 정보 사본**을 사용한다. 그래야 지난달 시험과 오늘 시험을 공정하게 비교할 수 있다. 실제 페이지를 가져오는 속도·성공률은 별도 서버 부하 시험에서 확인한다.

이 프로젝트의 최종 시험 통과 기준은 카테고리 정답률 85% 이상, 목적을 연결했다고 답한 것 중 틀린 연결 5% 이하, 일부러 애매하게 만든 문제에서 “모르겠다”라고 답한 비율 80% 이상이다.

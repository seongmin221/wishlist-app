# QA-CLI-001: 웹뷰의 새 창, 외부 앱 이동과 복귀

> 상태: **학습 Q&A** · 날짜: 2026-09-05

## 질문

웹뷰에서 새 창 링크, 외부 앱 실행, 외부 앱에서 기존 웹뷰로 돌아온다는 것은 각각 무엇인가?

## 짧은 답변

- **새 창 링크**는 웹페이지가 `target="_blank"` 또는 `window.open()` 등을 사용해 현재 페이지와 별도의 브라우징 화면을 열어 달라고 요청하는 것이다. 일반 브라우저는 새 탭이나 팝업을 만들지만, native 웹뷰에서는 앱이 같은 웹뷰에 열지, 새 웹뷰를 만들지, 외부 브라우저로 보낼지 정해야 한다.
- **외부 앱 실행**은 `https` 페이지를 웹뷰에 표시하는 대신 결제 앱, 전화, 메일, 앱스토어처럼 다른 앱이 처리하는 링크를 OS에 넘기는 것이다. 사용자 탭으로 시작된 이동과 페이지의 자동 리다이렉트를 구분해야 원하지 않는 앱 실행을 줄일 수 있다.
- **외부 앱에서 웹뷰로 복귀**한다는 것은 결제 앱 등으로 잠시 이동한 뒤 위시리스트 앱이 다시 활성화될 때, 웹뷰를 닫지 않고 기존 URL·스크롤·탐색 기록을 이어 보여주는 동작이다. 앱 프로세스가 종료될 가능성까지 고려하면 최소한 원래 상품 URL과 앱 navigation 상태는 복원할 수 있어야 한다.

## 예시

- 쇼핑몰의 `사이즈표` 버튼이 새 팝업을 요청한다.
- `카카오페이로 결제` 버튼이 설치된 결제 앱을 요청한다.
- 결제 앱 사용 후 위시리스트 앱으로 돌아오면 열어 두었던 쇼핑몰 페이지가 다시 보인다.

위시리스트 앱은 결제 주체가 아니므로 외부 앱에서 돌아왔다는 사실만으로 구매 성공을 확정할 수 없다. 구매 결정과 아카이브는 사용자가 앱에서 명시적으로 수행해야 한다.

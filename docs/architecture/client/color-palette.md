# 색 팔레트와 글자색 규칙

> 상태: **확정** · 최종 갱신: 2026-09-27 · 관련: [시각 디자인 방향](../../history/product-planning/mvp/decisions/visual-direction.md), [헤드라인 둘째 줄 색 계산](headline-secondary-color.md)

## 목적

컬러풀한 블록 면을 쓰면서도 글자 대비를 지키도록 색 팔레트와, 색 면 위 글자색 규칙을 정한다. 값은 OKLCH로 설계하고 sRGB 16진수로 쓴다.

## 바탕과 쓰는 곳

- 화면 바탕은 `#F7F7F3`이다.
- 색은 **블록 면**에만 쓴다: 홈 챙길 일 블록, 목적 블록, 목적 상세와 아카이브 기록 상세의 머리 면, 목적 점.
- 상품 목록 카드, 시트, 카테고리 목록은 무채색으로 둔다. 상품 사진이 이미 알록달록해서 옆에 선명한 면을 두면 부딪힌다.

### 역할

- 홈 챙길 일 블록: `분류·목적 확인` 연두, `정보 보완 필요` 노랑, `정보 가져오는 중` 하늘.
- 목적 색: 앱이 정해진 순서로 붙인다. 이웃한 목적끼리 색이 비슷하지 않게 보라 → 하늘 → 코랄 → 연두 → 분홍 → 민트 → 노랑 → 파랑 → 토프 → 주황 → 초록 → 라일락 → 베이지 → 회색 순서를 쓴다.
- 아카이브 목록처럼 흰 면 위에 목적 색을 작은 점으로 쓸 때는 테두리 없이 면 색 그대로 쓴다.

## 색 면 위 글자색

- **본문 글자**: 먹색 `#111111`. 모든 블록 색에서 대비 4.5:1 이상이다.
- **헤드라인 둘째 줄**(22px 굵은 글자): [헤드라인 둘째 줄 색 계산](headline-secondary-color.md)의 공식(면 45% + 먹색 55%)으로 만들고, 3:1에 못 미치면 면 비중을 낮춘다.
- **작은 보조 글자**(라벨·설명, 10~13px): 같은 식에서 면 비중을 낮춰 **4.5:1**을 맞춘 색을 쓴다. 기본 바탕에서 쓰던 먹색 62% 투명도는 선명한 면 위에서 대비가 떨어진다(보라 3.2:1, 코랄 3.4:1)라 색 면 안에서는 쓰지 않는다.
- 각 색의 두 톤은 앱이 정한 고정 팔레트이므로 표의 값을 색 토큰으로 둔다.

## 검토한 안

- 채도: 중간(C 0.08~0.14)과 강하게(C 0.14~0.18)를 비교해 **강하게**를 택했다.
- 짙은 색(올리브·짙은 보라·벽돌·남색, 흰 글자)을 섞는 안을 함께 비교했고, 이번 세트에는 넣지 않았다.
- 바탕: `#F7F7F3`, 순수 회색 `#EDEDED`, 크림 `#EFECDF`, 흰색 `#FFFFFF`을 비교해 `#F7F7F3`을 유지했다.
- 이전 파스텔 블록 색(C 0.02~0.11, L 0.87~0.92)은 차분하지만 레퍼런스처럼 컬러풀하지 않아 대체했다.

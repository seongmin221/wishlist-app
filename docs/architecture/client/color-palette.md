# 색 팔레트와 글자색 규칙

> 상태: **확정** · 최종 갱신: 2026-09-28 · 관련: [시각 디자인 방향](../../history/product-planning/mvp/decisions/visual-direction.md), [헤드라인 둘째 줄 색 계산](headline-secondary-color.md)

## 목적

컬러풀한 블록 면을 쓰면서도 글자 대비를 지키도록 색 팔레트와, 색 면 위 글자색 규칙을 정한다. 값은 OKLCH로 설계하고 sRGB 16진수로 쓴다.

## 바탕과 쓰는 곳

- 화면 바탕은 `#F7F7F3`이다.
- 색은 **블록 면**에만 쓴다: 홈 챙길 일 블록, 목적 블록, 목적 상세와 아카이브 기록 상세의 머리 면, 목적 점.
- 상품 목록 카드, 시트, 카테고리 목록은 무채색으로 둔다. 상품 사진이 이미 알록달록해서 옆에 선명한 면을 두면 부딪힌다.

## 블록 색 (확정 톤 +)

`확정 디자인`의 블록 색 톤을 이어받아 한 단계 선명하게 한 14색이다. 선명한 색 11개(채도 C 0.06~0.13, 밝기 L 0.85~0.90)와 쉬어 가는 색 3개(토프·베이지·회색)로 이뤄진다. 모든 색 위 글자는 먹색 `#111111`이다.

### 역할

- 홈 챙길 일 블록: `분류·목적 확인` 연두, `정보 보완 필요` 노랑, `정보 가져오는 중` 하늘.
- 목적 색: 앱이 정해진 순서로 붙인다. `확정 디자인`처럼 보라 → 하늘 → 살구로 시작하고, 이웃한 목적끼리 색이 비슷하지 않게 보라 → 하늘 → 주황(살구) → 연두 → 분홍 → 민트 → 노랑 → 파랑 → 토프 → 코랄 → 초록 → 라일락 → 베이지 → 회색 순서를 쓴다.
- 아카이브 목록처럼 흰 면 위에 목적 색을 작은 점으로 쓸 때는 먹색 20% 테두리(1px)를 두른다. 옅은 면 색은 흰 바탕에서 경계가 흐려지기 때문이다.

## 색 면 위 글자색

- **본문 글자**: 먹색 `#111111`. 모든 블록 색에서 대비 11:1 이상이다.
- **헤드라인 둘째 줄**(22px 굵은 글자): [헤드라인 둘째 줄 색 계산](headline-secondary-color.md)의 공식(면 45% + 먹색 55%)으로 만들고, 3:1에 못 미치면 면 비중을 낮춘다.
- **작은 보조 글자**(라벨·설명, 10~13px): 같은 식에서 면 비중을 낮춰 **4.5:1**을 맞춘 색을 쓴다. 색 면 안에서는 기본 바탕에서 쓰던 먹색 62% 투명도 대신 이 색을 써서 글자가 면 색을 따라가게 한다. 강하게 세트를 검토할 때 먹색 62%가 선명한 면 위에서 대비가 떨어진 것(보라 3.2:1, 코랄 3.4:1)이 이 규칙을 만든 계기다.
- 각 색의 두 톤은 앱이 정한 고정 팔레트이므로 표의 값을 색 토큰으로 둔다.

## 무채색 단계 (확정)

흩어져 있던 회색 11가지를 바탕 `#F7F7F3`의 색조(H 106)로 맞춘 6단계로 묶는다(A안). 먹색과 흰 카드는 그대로 둔다.

| 단계 | 값 | 쓰는 곳 | 대체한 값 |
| --- | --- | --- | --- |
| 카드 | `#FFFFFF` | 흰 카드, 시트, 검은 버튼 위 글자 | — |
| 바탕 | `#F7F7F3` | 화면 바탕 | — |
| 옅은 면 | `#F2F2EE` | 원형 버튼, 아이콘 칸, 작은 사진 바탕 | `#F0F0EB`, `#EFEFEA` |
| 칩 | `#EAEAE4` | 전환 버튼 바탕, 필터 pill | `#ECECE6`, `#E9E9E3` |
| 비활성 면 | `#E4E4DE` | 비활성 버튼 바탕 | `#E5E5E0` |
| 보조 | `#A0A099` | › 화살표, 비활성 글자 | `#A5A59E`, `#9C9C95` |
| 먹색 | `#111111` | 글자, 검은 버튼 | — |

- 보조 글자와 선은 따로 회색을 두지 않고 먹색의 투명도(62%, 50%, 20%, 10%)로 쓴다.
- 먹색 `#181811`과 카드 `#FDFDFB`까지 바탕 색조를 넣는 B안과 비교해 A안을 택했다.

## 검토한 안

- 강하게 세트(C 0.10~0.18, 밝기 L 0.65~0.89)로 한 번 정하고 `UI 피드백 적용` 페이지에 입혔다. 이후 `확정 디자인` 블록 색 느낌의 후보를 더 보기로 했다. 확정 톤(C 0.02~0.11)과 확정 톤 +(C 0.06~0.13)를 강하게 세트와 비교해 **확정 톤 +**를 택했다(2026-09-28).
  - 강하게 세트 값: 노랑 `#FCDA2A`, 주황 `#FE852A`, 코랄 `#F76560`, 분홍 `#FF93C1`, 라일락 `#CF8DE4`, 보라 `#8F7DF3`, 파랑 `#518FE9`, 하늘 `#7AC8F5`, 민트 `#5FD2BA`, 초록 `#3FC168`, 연두 `#BFEB56`, 토프 `#B69F97`, 베이지 `#D9C8AA`, 회색 `#C4C4C1`
- 채도 중간 세트(C 0.08~0.14)도 비교했다.
- 짙은 색(올리브·짙은 보라·벽돌·남색, 흰 글자)을 섞는 안을 함께 비교했고, 넣지 않기로 확인했다.
- 바탕: `#F7F7F3`, 순수 회색 `#EDEDED`, 크림 `#EFECDF`, 흰색 `#FFFFFF`을 비교해 `#F7F7F3`을 유지했다.

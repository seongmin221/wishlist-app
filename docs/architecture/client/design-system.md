# 디자인 시스템

> 상태: **구축 중** · 최종 갱신: 2026-09-28 · 관련: [색 팔레트와 글자색 규칙](color-palette.md), [헤드라인 둘째 줄 색 계산](headline-secondary-color.md), [시각 디자인 방향](../../history/product-planning/mvp/decisions/visual-direction.md)

## 목적

iOS와 Android가 같은 화면을 만들 수 있도록, 확정 디자인에서 쓰는 값과 공통 요소를 한곳에 모은다. 값은 새로 정한 것이 아니라 확정 보드(디자인 캔버스 버전 295)에서 센 것이다. 캔버스의 `디자인 시스템` 페이지에 같은 내용이 보드로 있다(DS-COLOR, DS-TYPE, DS-SPACE, DS-COMP, DS-REVIEW).

## 색

값과 대비 규칙은 [색 팔레트와 글자색 규칙](color-palette.md)을 따른다. 여기서는 역할만 정리한다.

- 화면 틀은 무채색 단계(카드 `#FFFFFF`, 바탕 `#F7F7F3`, 옅은 면 `#F2F2EE`, 칩 `#EAEAE4`, 비활성 면 `#E4E4DE`, 보조 `#A0A099`, 먹색 `#111111`)로 그린다.
- 보조 글자와 선은 먹색 투명도로 쓴다.
  - 62%: 보조 글자, 설명
  - 50%: 헤드라인 둘째 줄
  - 30%: 흐린 글자(구매하지 않은 후보)
  - 20%: 테두리, 목적 점 테두리
  - 10%: 구분선
  - 6%: 옅은 구분선
- 색은 블록 면에만 쓴다(확정 톤 + 14색). 색 면 위 글자는 먹색이고, 둘째 줄과 작은 글자는 같은 색의 어두운 톤이다.
- 위험 동작은 글자·버튼 `#B42318`, 아이콘 칸 `#FDECEA`이다.
- 시트와 메뉴 뒤 덮개는 바탕색 40%와 흐림 6px이다.

## 글꼴

## 간격·모서리·그림자

- 간격 단계: 2, 3, 4, 6, 8, 10, 12, 14, 18, 20px
- 화면 배치
  - 화면 글자 여백 20: 헤드라인, 라벨, 뒤로 가기의 양옆
  - 목록 양옆 6: 상품 목록과 블록 목록. 블록 사이도 6
  - 상품 목록: 열 사이 4, 행 사이 10, 390pt 폭에서 카드 폭 187
  - 화면 위 여백 58: 상태 표시줄 포함
  - 떠 있는 시트: 양옆 12, 아래 16
  - 하단 탭: 양옆 20, 아래 28
  - 누르는 영역: 최소 44
- 모서리
  - 999: 버튼, pill, 탭, 원형 버튼
  - 32: 머리 면의 아래 모서리
  - 28: 떠 있는 시트
  - 20: 블록, 길게 누르기 메뉴
  - 16: 상품 사진과 카드
  - 12: 36px 아이콘 칸
  - 9: 30px 아이콘 칸
- 그림자
  - 떠 있는 시트: `0 12px 40px -12px` 먹색 25%
  - 길게 누르기 메뉴: `0 16px 48px -12px` 먹색 30%
  - 떠 있는 검은 버튼: `0 8px 24px -8px` 먹색 40%

## 정리할 값

확정 보드를 모으다 규칙에서 벗어난 값을 찾았다. 캔버스 `디자인 시스템` 페이지의 DS-REVIEW 보드에 후보를 그렸고, 결정 전이다.

1. 위험 빨강: 길게 누르기 메뉴의 `삭제`만 `#C23B2A`이고 나머지는 `#B42318`이다.
2. 빈 홈 저장 방법 글자: 단계 숫자 `#D9D9D2`와 제목 `#6E6E68`이 무채색 단계 밖의 회색이다.
3. 빈 홈 목적 카드 면: `챙길 일을 다 끝냈어요` 홈의 고르는 중인 목적 카드가 비활성 면 `#E4E4DE`를 쓴다.
4. 기본 버튼 높이: 기본 버튼은 52px인데 후보 추가 창의 넣기 버튼만 54px이다.

- 캔버스 보드는 `design/canvas/gen_design_system.py`가 확정 보드에서 만든다.

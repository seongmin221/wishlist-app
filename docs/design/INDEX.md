# 디자인 문서 INDEX

화면 디자인은 Claude Design 캔버스에서 진행하고 추적한다. 레포에는 캔버스 위치와 확정된 결정만 남긴다.

- [위시리스트 디자인 캔버스](https://claude.ai/artifact/DDuoeFQ7k7i9yBqY2H9qDK) — 진행 순서는 레퍼런스 보드 → 내비게이션 구조 → 흑백 와이어프레임 → 시각 방향 → 전체 화면이다. 페이지 구성:
  - `레퍼런스`: 모든 디자인 검토의 고정 기준점 (REF-01~04)과 확정한 서체 규칙·목적 색·바탕·모서리·위험 색
  - `와이어프레임`: 흑백 와이어프레임 전체 (홈, 카테고리, 목적, 상품, 카테고리 선택, 웹뷰, 아카이브, 카테고리 관리, 로그인·설정·공유 수신)
  - `흐름도`: 화면 사이의 이동을 한 장으로 정리한 흐름도
  - `시각 방향 · 대표 화면`: 확정한 시각 규칙을 입힌 홈·카테고리 첫 화면·목적 첫 화면·목적 상세 (라이트·다크)
  - `전체 화면 · 라이트`, `전체 화면 · 다크`: 시각 규칙을 와이어프레임 전체 화면에 입히는 중 (홈 계열, 카테고리, 목적, 상품, 아카이브, 로그인·설정·공유·웹뷰 완료)
  - `검토 · 정보 아이콘 색`: 정보성 아이콘 타일 색 후보 (B 상태 색으로 결정)
  - `검토 · 보조 서체·위험 색`: 보조 라벨 서체와 위험 색을 고른 비교 (둘 다 A로 결정)
- [디자인 핸드오프](../../design/handoff/README.md) — 캔버스 밖 도구(Codex 등)용 사본. 완성 화면(라이트·다크 보드 104개, 구현 기준), 인터랙션·애니메이션, 와이어프레임·흐름도
- [디자인 결정](decisions.md) — 재디자인에서 확정한 시각 방향, 내비게이션 구조, 스크롤 원칙

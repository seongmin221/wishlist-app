# 제품 결정: AI 목적 자동 연결과 재판단

> 상태: **확정** · 날짜: 2026-09-05 · 영역: **제품·AI**

## 결정

- AI는 사용자가 이미 만든 목적에만 새 상품을 연결한다.
- 자동 연결에는 상품명·카테고리 등 상품을 식별할 정보와, 목적의 이름·설명 또는 기존 포함 상품을 바탕으로 한 연결 근거가 필요하다.
- 최소 근거를 충족하는 목적이 여러 개면 가장 부합하는 목적 하나를 자동 연결한다. 앱 진입 후 `분류·목적 확인`에서 사용자가 결과를 검토할 수 있으므로 여러 후보가 있다는 이유만으로 `목적 미지정`으로 남기지 않는다.
- 어떤 목적도 최소 근거를 충족하지 못하면 `목적 미지정`으로 둔다.
- AI가 연결했고 사용자가 아직 확정하지 않은 목적만, 상품 정보 또는 기존 목적 정보가 의미 있게 바뀌었을 때 다시 판단할 수 있다.
- 사용자가 한 번 확정한 목적은 해당 목적이 삭제되거나 사용자가 직접 수정하지 않는 한 자동으로 변경하지 않는다.
- 목적 삭제로 `확정된 목적 미지정`이 된 상품은 AI가 다른 목적에 자동 재연결하지 않는다.
- 새 목적을 만들어도 기존 상품 전체를 자동으로 다시 판단하지 않는다. 사용자가 직접 상품을 추가하거나 향후 별도 기능으로 명시적으로 요청할 때만 검토한다.
- MVP에서는 최초 추출 이후 상품 정보 변화를 주기적으로 모니터링하거나 자동 갱신하지 않는다.

## 판단 근거

목적은 상품의 객관적 속성이 아니라 사용자의 비교 의도다. 목적 이름·설명과 기존 포함 상품은 이 의도를 추정할 근거가 되지만, 자동 연결 결과는 틀릴 수 있으므로 진입 화면의 검토 흐름을 유지한다.

검토 흐름이 있으므로 최소 근거를 충족한 후보가 여러 개일 때 AI가 가장 적합한 하나를 선택하는 편이 사용자의 분류 부담을 줄인다. 반대로 근거가 없는 연결은 만들지 않는다.

사용자 확정은 AI 예측보다 우선한다. 확정 이후의 자동 재판단을 막아 사용자의 명시적인 분류가 뒤집히지 않게 하고, 새 목적 생성으로 기존 위시리스트 전체가 예기치 않게 바뀌는 것도 방지한다.

## 제품·구현 영향

- 목적 연결 결과에는 예측값과 사용자 확정값을 구분해 저장해야 한다.
- 재판단 대상은 AI 예측 상태이면서 아직 사용자가 확정하지 않은 상품으로 제한해야 한다.
- 목적 후보 선택은 최소 근거 충족 여부를 먼저 검사하고, 통과한 후보 중 가장 적합한 하나를 반환해야 한다.
- 목적 삭제와 사용자 직접 수정은 확정값을 변경하는 명시적 사용자 행동으로 처리한다.
- 상품 정보의 주기적 감시나 그로 인한 목적 재판단 작업은 MVP에 포함하지 않는다.

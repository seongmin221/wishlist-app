# 제품 결정: 아카이브와 삭제 안전장치

> 상태: **확정** · 날짜: 2026-09-05 · 최종 갱신: 2026-09-10 · 영역: **제품 공통**

## 목적 종료와 아카이브

- 사용자는 구매 상품을 지정하거나 지정하지 않은 채 목적과 모든 비교 후보를 일괄 아카이브할 수 있다.
- 포함된 상품이 하나도 없는 빈 목적은 아카이브할 수 없고 삭제만 할 수 있다.
- 일괄 아카이브 전에 확인창을 표시한다. 구매 상품을 지정했다면 이를 표시하고, 함께 아카이브될 후보의 수와 목록을 보여준다.
- 아카이브 제목은 구매 상품 지정 여부와 관계없이 목적 이름을 기본값으로 사용하며 이후 수정할 수 있다.
- 아카이브에서는 포함된 제품명을 함께 보여준다. 구매 상품을 지정한 경우에만 해당 상품을 별도로 표시한다.
- 아카이브된 목적, 선택적으로 지정된 구매 상품, 비교 후보와 당시 카테고리 이름은 아카이브 시점의 스냅샷으로 보존한다.

## 아카이브 취소

- 아카이브 취소는 아카이브 목록의 상세 화면에서만 제공한다.
- 취소하면 원래 목적과 포함된 모든 상품을 활성 상태로 일괄 복원한다.
- 지정된 구매 상품이 있다면 그 결정을 취소하고 해당 아카이브 묶음을 목록에서 제거한다.
- 아카이브 안의 상품을 개별적으로 복원하는 동작은 제공하지 않는다.
- 이 동작은 기록을 유지한 채 상품을 복사하는 것이 아니라 아카이브 작업 전체를 되돌리는 것이다.

## 아카이브 삭제

- 아카이브 기록은 묶음 전체만 삭제할 수 있다.
- 아카이브 안의 개별 상품 삭제는 제공하지 않는다.
- 아카이브 묶음 삭제 후 실행 취소는 제공하지 않는다.

## 활성 상품 삭제

- 활성 상품 삭제는 아카이브와 별도의 동작이다.
- 삭제 후 실행 취소는 제공하지 않는다.
- 삭제 확인창에는 상품이 연결된 목적 이름과, 삭제하면 해당 목적의 비교 후보에서도 제거된다는 사실을 표시한다.
- 모든 영향을 확인창 본문에 나열하지 않는다. 사용자가 `?` 도움말을 누르면 다음 상세 정보를 표시한다.
  - 삭제 후 목적에 남는 상품 수
  - 마지막 상품을 삭제해도 목적은 자동 삭제되지 않고 빈 상태로 유지된다는 점
  - 기존 아카이브 스냅샷에는 영향이 없다는 점
- 목적 미지정 상품에는 목적 영향 안내를 표시하지 않는다.
- 상품을 삭제해도 목적 자체와 다른 상품은 변경하지 않는다.

## 판단 근거

목적 종료는 여러 상품과 목적을 한 번에 이동시키므로 실행 전에 영향 범위를 직접 확인할 필요가 있다. 구매하지 않기로 한 비교도 기록할 가치가 있으므로 구매 상품 지정은 선택 사항으로 둔다. 비교한 상품이 없는 빈 목적에는 보존할 후보 기록이 없으므로 삭제만 허용한다. 반면 실수로 아카이브한 경우에는 상세 화면에서 작업 전체를 취소할 수 있으므로 개별 복원으로 기록과 활성 상태가 섞이는 복잡성을 피한다.

상품 삭제 확인창은 핵심 결과를 즉시 이해할 수 있게 간결하게 유지한다. 자주 필요하지 않은 세부 영향은 `?` 도움말로 분리해 필요한 사용자만 확인할 수 있게 한다.

아카이브는 하나의 목적 종료 기록이므로 내부 상품을 개별 삭제하지 않고 묶음 단위로만 관리한다.

## 제품·구현 영향

- 일괄 아카이브 확인 UI는 선택된 구매 상품이 있을 때 이를 표시하고, 후보 수와 후보 목록을 제공해야 한다.
- 아카이브 데이터는 구매 상품을 선택 사항으로 저장하고, 목적 이름을 기본 제목으로 보존해야 한다.
- 서버와 클라이언트는 포함 상품이 없는 목적의 아카이브 요청을 허용하지 않아야 한다.
- 아카이브 취소는 목적·상품 활성화, 선택된 구매 결정 취소와 아카이브 묶음 제거를 하나의 일관된 작업으로 처리해야 한다.
- 삭제 확인 UI는 목적 요약과 `?` 상세 영향 도움말을 제공해야 한다.
- 중복 검토에서 기존 상품 삭제를 선택한 경우에도 연결된 목적에 대한 같은 영향 정보를 제공해야 한다.

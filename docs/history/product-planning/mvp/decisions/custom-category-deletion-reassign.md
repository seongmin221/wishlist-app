# 제품 결정: 사용자 전용 카테고리 삭제 뒤 재지정을 정보 보완으로 합침

> 상태: **확정** · 날짜: 2026-10-02 · 영역: **제품 공통** · 대체: [사용자 전용 카테고리 변경과 삭제](custom-category-lifecycle.md)의 재지정 흐름·`카테고리 미지정` 영역 부분

## 결정

- 연결된 상품이 있는 사용자 전용 카테고리를 삭제해도 상품은 삭제하지 않는다. 삭제 직후 연속 재지정 화면은 두지 않는다.
- 카테고리가 빈 상품은 홈의 `정보 보완 필요`에 표시하고, 사용자는 그곳의 연속 처리에서 카테고리를 다시 고른다.
- 별도의 `카테고리 미지정` 조치 영역은 두지 않는다.
- 상품이 없는 사용자 전용 세부 카테고리도 카테고리 목록에 보이며, 변경과 삭제는 그 카테고리의 상품 목록 화면에서만 한다.

## 판단 근거

삭제 직후 재지정 화면을 띄우면 삭제라는 한 동작이 긴 작업으로 바뀌고, 건너뛴 상품을 위해 홈에 영역이 하나 더 생긴다. 카테고리가 비었다는 것은 결국 "목록에 쓸 필수 정보가 빠졌다"는 상태이므로, 이미 있는 `정보 보완 필요`의 연속 처리로 모으면 홈 영역 수가 줄고 처리 방법이 하나로 통일된다.

## 제품·구현 영향

- 홈 조치 영역은 `분석 대기`, `분류 중`, `정보 보완 필요`, `분류·목적 확인` 네 가지다.
- `정보 보완 필요` 조건에 "사용자 전용 카테고리 삭제로 카테고리가 비었음"을 더한다.

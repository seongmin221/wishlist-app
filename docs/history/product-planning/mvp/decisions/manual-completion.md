# 제품 결정: 상품 정보 직접 보완의 완료 기준

> 상태: **확정** · 날짜: 2026-09-10 · 영역: **제품·클라이언트·서버**

## 결정

- 상품을 일반 목록에서 사용하기 위한 필수 정보는 제품명과 카테고리다.
- 대표 이미지, 가격, 통화, 판매처, 브랜드와 목적은 선택 정보다.
- 대표 이미지가 없으면 기본 이미지를 표시하고 사용자가 나중에 추가할 수 있다.
- `PARTIAL` 또는 `FAILED` 항목도 사용자가 제품명과 카테고리를 모두 입력하면 `정보 보완 필요`에서 빠지고 일반 카테고리 목록으로 이동한다.
- 사용자가 직접 보완을 저장한 항목은 이후 서버 재분석 대상에서 제외하고, 직접 입력한 정보로 계속 사용한다.
- 직접 보완 뒤에도 원래 서버 추출 실패 기록은 내부 진단 정보로 유지한다.

사용자 전용 카테고리 삭제 뒤 재지정을 건너뛴 항목은 기존 정책에 따라 `카테고리 미지정` 영역에 둔다. 이는 추출 실패나 직접 보완 미완료와 구분한다.

## 판단 근거

비교 목록에서 상품을 식별하고 분류하려면 제품명과 카테고리가 필요하다. 대표 이미지나 가격을 필수로 요구하면 추출할 수 없는 사이트의 상품을 사용자가 직접 복구하기 어려워진다. 최소 정보만 채우면 정상적으로 사용할 수 있게 하되, 추출 실패 원인은 운영과 진단을 위해 별도로 보존한다.

## 제품·구현 영향

- 화면 노출 위치는 서버 추출 상태만으로 정하지 않고 제품명·카테고리 충족 여부를 함께 판단해야 한다.
- 대표 이미지가 없는 일반 상품 카드에는 기본 이미지가 필요하다.
- 직접 보완 저장 여부를 관리하고, 해당 항목에는 재분석 행동을 제공하지 않아야 한다.

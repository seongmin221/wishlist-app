# MVP 제품 기획 이력

MVP 출시 범위에서 제품 방향을 정하고 구체화한 체크포인트와 결정 기록이다. 현재 제품 규칙의 기준은 [제품 문서 INDEX](../../../product/INDEX.md)이며, 이 폴더의 기록은 당시의 맥락과 판단 근거를 보존한다.

## 기획 진행 순서

1. [초기 방향](checkpoints/initial-direction.md) — 대체됨 · 2026-08-29
2. [목적 점검](checkpoints/purpose-review.md) — 대체됨 · 2026-08-29
3. [taxonomy와 목적](checkpoints/taxonomy-and-purpose.md) — 대체됨 · 2026-09-04
4. [정책 구체화](checkpoints/policy-completion.md) — 대체됨 · 2026-09-05

초기 방향과 정책 구체화 체크포인트는 현재 제품 기준이 [제품 문서 INDEX](../../../product/INDEX.md)로 전환되며 대체됐다.

## 기록 유형

- [체크포인트](checkpoints/INDEX.md): 세션별 진행 상태와 다음 재개 지점
- [결정](decisions/INDEX.md): MVP 사용자 흐름별로 구체화한 정책과 trade-off

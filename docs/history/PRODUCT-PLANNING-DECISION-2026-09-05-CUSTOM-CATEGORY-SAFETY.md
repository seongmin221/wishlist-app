# 제품 결정: 사용자 전용 카테고리 입력과 AI 안전성

> 상태: **확정** · 날짜: 2026-09-05 · 영역: **제품·AI**

## 생성 한도와 입력 규격

- 사용자 전용 카테고리는 출시 시 사용자당 최대 20개까지 만들 수 있다.
- 20개를 초과하는 실제 수요가 확인되면 한도 상향을 검토한다.
- 이름은 최대 40자다.
- 설명은 최대 200자다.
- 포함 예시는 최대 5개이며, 각 예시는 최대 60자다.
- 같은 상위 카테고리 아래에서는 앞뒤·연속 공백을 정리한 이름이 같은 사용자 전용 카테고리를 중복 생성할 수 없다.
- 서로 다른 상위 카테고리에서는 같은 이름을 허용한다.

## 생성 요청을 거부하는 경우

- 이름이 비어 있음
- 이름·설명·예시의 길이 또는 개수 제한 초과
- 표시할 수 없는 제어문자 포함
- 짧은 시간 동안 과도한 생성 요청 반복

## AI 후보에서만 제외하는 경우

- `이전 지시를 무시해`와 같은 명령문 형태의 prompt injection
- URL·코드·스크립트가 중심인 이름·설명·예시
- AI 입력에 부적절한 유해 텍스트

이 경우 사용자 전용 카테고리는 입력한 그대로 개인 목록에 유지한다. 사용자는 상품에 직접 지정할 수 있지만 AI 자동 분류 후보로는 사용하지 않는다. 사용자 텍스트를 자동 수정하지 않으며, AI 후보 제외 여부는 MVP 화면에 별도로 노출하지 않는다.

## 판단 근거

20개 한도는 출시 시 과도한 생성과 AI 입력 크기를 제한하면서 개인 분류를 사용할 여지를 제공한다. 추측으로 큰 한도를 제공하기보다 실제 수요를 확인한 뒤 조정한다.

형식적으로 잘못된 입력과 과도한 요청은 생성 단계에서 막는다. 반면 개인 목록에서 사용할 수 있는 텍스트를 AI 적합성만으로 삭제하거나 수정하지 않는다. 저장·직접 지정 권한과 AI 입력 자격을 분리하면 사용자 제어권을 유지하면서 prompt injection과 불필요한 모델 입력을 줄일 수 있다.

## 제품·구현 영향

- 서버는 사용자별 카테고리 수, 필드 길이·개수와 동일 상위 카테고리 안의 정규화된 이름 중복을 검증해야 한다.
- 생성 API에는 과도한 반복 요청을 제한하는 rate limit이 필요하다.
- 사용자 전용 카테고리에는 AI 후보 포함 여부와 내부 제외 사유를 저장할 수 있어야 한다.
- LLM 요청에는 AI 후보로 허용된 카테고리만 구조화된 데이터로 전달해야 한다.

# 제품 결정: 홈 조치 필요 영역의 우선순위

> 상태: **확정** · 날짜: 2026-09-10 · 영역: **제품·클라이언트**

## 결정

- 하나의 상품은 홈의 조치 필요 영역 한 곳에만 표시한다.
- 여러 조건이 겹치면 다음 순서로 표시 영역을 정한다.
  1. 서버 전송 전: `분석 대기`
  2. 서버 분석 중: `분류 중`
  3. 제품명 누락 또는 추출 결과에서 카테고리를 정하지 못함: `정보 보완 필요`
  4. 사용자 전용 카테고리 삭제로 카테고리가 없어짐: `카테고리 미지정`
  5. 필수 정보는 있지만 자동 분류 결과가 미확정: `분류·목적 확인`
- 위 조건에 해당하지 않으면 홈의 조치 필요 영역에 표시하지 않는다.
- 제품명과 카테고리가 있는 상품은 `분류·목적 확인` 전이라도 일반 카테고리 목록에서 볼 수 있다. 검토는 상품 사용을 막는 절차가 아니다.
- 각 조치 필요 영역에 해당하는 항목이 없으면 그 영역을 표시하지 않는다.

## 판단 근거

같은 상품을 여러 조치 영역에 동시에 보여주면 사용자는 서로 다른 작업이 필요한 항목으로 오해할 수 있다. 먼저 해결해야 하는 상태를 하나만 보여주면 다음 행동이 분명해진다. 반면 자동 분류 검토를 일반 목록 진입 조건으로 사용하면 저장 흐름에 사실상의 확인 절차가 생기므로, 필수 정보가 있는 상품은 검토 전에도 목록에서 사용할 수 있게 한다.

## 제품·구현 영향

- 홈 표시 상태는 추출 상태, 필수 정보 충족 여부, 카테고리 삭제 여부와 검토 상태를 정해진 순서로 평가해야 한다.
- 홈의 조치 영역과 일반 카테고리 목록 포함 여부는 별도로 판단해야 한다.
- 상세 배치와 시각 디자인은 화면 설계 단계에서 정한다.

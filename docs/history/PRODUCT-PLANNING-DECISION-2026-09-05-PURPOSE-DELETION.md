# 제품 결정: 연결된 상품이 있는 목적 삭제

> 상태: **확정** · 날짜: 2026-09-05 · 영역: **제품 공통**

## 결정

- 연결된 활성 상품이 있는 목적을 삭제하면 목적만 삭제한다.
- 해당 상품은 삭제하거나 아카이브하지 않고 모두 `목적 미지정`으로 전환한다.
- 이 전환은 사용자가 목적 삭제를 명시적으로 확정한 결과이므로, 상품의 목적 상태는 `확정된 목적 미지정`으로 본다. 해당 상품을 `분류·목적 확인` 대상으로 다시 올리지 않는다.
- 삭제 확인창에는 목적이 `미지정`으로 전환될 상품 수를 명시한다.
- 사용자는 확인창의 드롭다운을 펼쳐 영향을 받는 상품 목록을 확인할 수 있다.
- 삭제 직후 실행 취소는 제공하지 않는다.
- 아카이브된 목적과 후보 관계는 활성 목적과 분리된 아카이브 시점의 스냅샷으로 보존한다. 활성 목적의 삭제는 기존 아카이브 기록에 영향을 주지 않는다.

## 판단 근거

목적은 상품 자체나 기본 카테고리가 아니라 사용자가 상품을 비교하는 선택적 맥락이다. 따라서 목적 삭제가 상품 삭제로 이어지지 않아야 한다. 사용자가 삭제 영향을 확인하고 직접 확정하므로 연결이 해제된 상품을 다시 검토 대상으로 올릴 필요도 없다.

아카이브는 과거 구매 결정과 당시의 비교 후보를 보여주는 기록이다. 활성 목적과 같은 생명주기를 사용하면 이후의 목적 삭제·변경으로 과거 기록이 훼손될 수 있으므로 별도 스냅샷으로 유지한다.

## 제품·구현 영향

- 목적 삭제 확인 UI는 영향받는 활성 상품의 개수와 펼쳐볼 수 있는 상품 목록을 제공해야 한다.
- 목적 삭제와 연결 상품의 `목적 미지정` 전환은 하나의 일관된 작업으로 처리해야 한다.
- 아카이브 화면은 활성 목적 데이터가 없어도 당시 목적과 후보를 표시할 수 있어야 한다.

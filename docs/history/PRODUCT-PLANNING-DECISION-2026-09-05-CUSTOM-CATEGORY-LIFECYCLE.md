# 제품 결정: 사용자 전용 카테고리 변경과 삭제

> 상태: **확정** · 날짜: 2026-09-05 · 영역: **제품 공통**

## 결정

- 공용 taxonomy의 카테고리는 사용자가 이름을 변경하거나 삭제할 수 없다.
- 사용자가 직접 만든 사용자 전용 세부 카테고리만 이름 변경과 삭제를 허용한다.
- 사용자 전용 카테고리의 이름을 변경하면 연결된 모든 활성 상품에 새 이름을 즉시 반영한다.
- 연결된 상품이 있는 사용자 전용 카테고리를 삭제하면, 삭제 후 별도 카테고리 재지정 흐름을 제공한다.
- 사용자는 각 상품의 카테고리를 다시 지정하거나 재지정을 건너뛸 수 있다.
- 재지정을 건너뛴 상품은 `정보 보완 필요`가 아니라 별도의 `카테고리 미지정` 영역에 표시한다.
- 삭제 확인창에는 영향을 받는 상품 수를 명시하고, 드롭다운을 펼쳐 해당 상품 목록을 확인할 수 있게 한다.
- 아카이브에는 당시 카테고리 이름을 스냅샷으로 보존한다. 이후 사용자 전용 카테고리의 이름을 변경하거나 삭제해도 기존 아카이브 기록은 바뀌지 않는다.

## 판단 근거

공용 taxonomy는 모든 사용자와 AI 분류가 공유하는 출시 기준이므로 개인이 변경할 수 없어야 한다. 반면 사용자 전용 카테고리는 개인 위시리스트의 관리 도구이므로 이름 변경과 삭제를 허용한다.

카테고리를 삭제한 직후 모든 상품의 대체 분류를 강제하면 삭제 흐름이 길어질 수 있다. 재지정을 건너뛸 수 있게 하되, 상품 정보 누락이나 추출 실패를 의미하는 `정보 보완 필요`와 구분해 `카테고리 미지정` 영역에서 다시 분류할 수 있게 한다.

아카이브는 과거 구매 결정 당시의 기록이므로 활성 카테고리의 생명주기와 분리한다.

## 제품·구현 영향

- 공용 카테고리에는 사용자용 이름 변경·삭제 동작을 노출하지 않는다.
- 사용자 전용 카테고리 삭제 확인 UI는 영향받는 상품의 개수와 펼쳐볼 수 있는 상품 목록을 제공해야 한다.
- 삭제 후에는 영향받는 상품을 연속해서 재분류할 수 있는 별도 흐름과 건너뛰기 동작이 필요하다.
- 재지정을 건너뛴 상품을 위한 `카테고리 미지정` 목록이 필요하다.
- 아카이브 화면은 활성 카테고리 데이터가 없어도 당시 카테고리 이름을 표시할 수 있어야 한다.

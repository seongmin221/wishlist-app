# 제품 taxonomy 초안

> 상태: **출시 기준 확정** · 최종 갱신: 2026-09-04

첫 출시에서 폭넓은 상품 URL을 수용하기 위한 공용 taxonomy 초안이다. 상위 카테고리는 탐색 단위이고, 세부 유형은 AI 분류와 기본 비교 목록의 단위다. 사용자는 이 목록에 없는 경우 자신의 상위 카테고리 아래에 사용자 전용 세부 카테고리를 추가할 수 있다.

첫 출시 taxonomy는 **상위 카테고리 11개, 세부 유형 87개**로 확정한다. 이후 범위 확대는 실제 사용자 로그를 검토해 결정한다.

공용 카테고리는 사용자가 이름을 변경하거나 삭제할 수 없다. 사용자가 추가한 개인용 세부 카테고리만 이름 변경과 삭제가 가능하며, 자세한 처리 규칙은 [제품 기능 및 스펙](product-spec.md)을 따른다.

## 출시 후 확장 기준

- 미분류 상태가 반복되는 상품 유형
- 같은 사용자 전용 세부 카테고리가 여러 사용자에게 반복해 생성되는 패턴
- 사용자가 AI 분류를 반복해서 다른 공용 카테고리로 수정하는 패턴
- `신발`처럼 하나의 세부 유형 안에서 서로 비교하지 않는 상품군이 누적되는 패턴

이 근거를 바탕으로 새 공용 세부 유형 또는 상위 카테고리 추가를 검토한다. 출시 전에는 추측만으로 범위를 계속 넓히지 않는다.

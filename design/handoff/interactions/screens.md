# 화면별 동작과 상태

[완성 화면](../screens/README.md) 보드에 들어 있는 동작을 화면별로 정리한 문서다. 시간·곡선은 [motion.md](motion.md)에 있고, 여기서는 **무엇을 누르면 무엇이 바뀌는지**와 **화면이 가진 상태**를 적는다.

- 보드 HTML의 `class Component`가 원본이다. `this.state = Object.assign({기본 상태}, {보드별 시작 상태})`의 첫 객체가 그 화면의 상태 목록이고, 두 번째 객체가 그 보드가 보여 주는 상태다(예: `FPurposeEditInPlace`는 `{ edit: true }`).
- `onClick`·`onScroll`·`onInput`에 연결된 함수 이름이 사용자 동작이다. 함수 안의 `setState`가 상태 전이다.
- 보드의 상품·목적 값은 예시 데이터다. 실제 데이터 규칙은 [제품 문서](../../../docs/product/INDEX.md)를 따른다.

## 공통 패턴

- **바텀시트**는 내용 높이만큼만 올라온다([모션](motion.md#1-바텀시트-열기닫기)). 손잡이는 실제로 끌어 움직이는 면(바텀시트, 목적·아카이브 상세의 목록 면)에만 있다. 막을 누르거나 닫기를 누르면 닫힌다.
- **편집 중 닫기 확인**: 편집 시트나 그 자리 편집에서 값을 바꾼 뒤(`dirty`) 취소·닫기를 누르면 "변경 사항을 버릴까요?" 확인창이 뜬다. `계속 편집`은 확인창만 닫고, `버리기`는 편집 전 값으로 되돌린다. 아무것도 바꾸지 않았으면 바로 닫힌다.
- **⋯ 메뉴**는 버튼 아래에 뜨는 작은 면(블러 없음, 1px 선)이다. 메뉴 밖을 누르면 닫히고, 항목을 고르면 메뉴가 닫힌 뒤 다음 시트·확인창이 열린다.
- **삭제·아카이브 확인창**의 "옮겨지는/지워지는 상품 n개" 줄을 누르면 같은 면 안에서 목록이 펼쳐지고 화살표가 뒤집힌다.
- **버튼 쌍**은 왼쪽 취소, 오른쪽 주 동작이다. 되돌릴 수 없는 마지막 확인만 빨강 면이다.
- **바로 고르는 시트**: 카테고리 선택 칩, 목적 선택 항목은 누르는 즉시 선택되고 시트가 닫힌다. 별도 확인 버튼이 없다.

## 화면별

### 홈

| 화면 | 동작 |
| --- | --- |
| FHome | 상태 `o1`·`o2`·`o3`(카드별 펼침). 할 일 카드 3개(분류·목적 확인, 정보 보완 필요, 분류 중)는 처음에 접혀 있다. 오른쪽 화살표를 누르면 상품 미리보기 캐러셀(가로 스크롤)이 펼쳐지고 화살표가 180° 돈다(200ms). 화살표 밖 카드 영역을 누르면 연속 처리 화면으로 간다. 분류 중은 갈 화면이 없어 카드 전체가 펼치기다. 캐러셀 상품을 누르면 그 상품부터 연속 처리를 시작한다. |
| FHomeLoggedOut | 상태 `open`. 분석 대기 카드가 같은 방식으로 접고 펼친다. |
| FHomeReviewFlow | 상태 `i`(현재 카드), `ok`·`later`(확정·보류 수), `dup`(비교 시트), `confirm`(`both`·`new`·`old` 확인창), `dupDone`(비교 결과). [모션](motion.md#4-연속-처리-카드-분류목적-확인). 카드가 겹쳐 쌓여 있고(남은 수만큼 뒤 카드 최대 2장), `확정`·`보류`를 누르거나 카드를 오른쪽·왼쪽으로 밀면 카드가 그 방향으로 기울며 날아가고 뒤 카드가 올라온다. 위에 `n / 전체` 위치, 끝나면 `확정 n · 보류 n` 요약과 `처음부터 다시 보기`가 나온다. 중복 후보가 있는 카드는 "같은 상품으로 보이는 항목이 있어요 · 비교"를 눌러 비교 시트를 연다. |
| FDuplicateCompare / Confirm* | 비교 시트에서 세 선택지 중 하나를 누르면 확인창이 뜬다. 둘 다 두기·기존 항목 지우기는 시트가 닫히고 카드에 결과 한 줄이 남으며 확정·보류는 그대로 이어서 한다. 새 항목 지우기는 그 카드를 건너뛰어 다음 카드로 간다. |
| FHomeFillFlow | 상태 `i`, `saved`·`skipped`. [모션](motion.md#5-정보-보완-넘김). 한 상품씩 `건너뛰기`·`저장하고 다음`으로 넘긴다. 두 버튼 모두 내용이 왼쪽으로 밀려 나가고 다음 상품이 오른쪽에서 들어온다. 끝나면 `저장 n · 건너뜀 n` 요약과 `처음부터 다시 보기`. |

### 카테고리

| 화면 | 동작 |
| --- | --- |
| FCategoryHome | 상태 `sel`(선택한 상위), `sheet`(`create`), `newTop`, `dirty`, `discard`. 세부 유형 칩을 누르면 칩 면이 자리 표시로 떠올라 목록 화면으로 커진다. 왼쪽 레일의 상위를 누르면 오른쪽 칩 목록이 바뀐다(마지막에 본 상위를 기억해 다시 연다). 칩 끝의 점선 `+ 추가`는 지금 보는 상위를 미리 고른 `신규 카테고리` 시트를 연다. |
| FCategoryList / ListCustom | 상태(직접 만든 카테고리) `menu`, `sheet`(`edit`), `del`, `delList`, `dirty`, `discard`. 상품 카드를 누르면 사진이 상세로 커진다. 목록 머리는 스크롤해도 위에 붙는다(sticky). 직접 만든 카테고리만 ⋯ 메뉴(편집 시트, 삭제 확인창)가 있다. 상세에서 돌아오면 보던 위치를 유지하고, 현재 탭을 다시 누르면 맨 위로 간다. |

### 목적

| 화면 | 동작 |
| --- | --- |
| FPurposeHome / Create | 상태 `open`(펼친 카드 번호), `create`(만들기 시트), `color`, `icon`, `dirty`. 목적 카드가 겹쳐 쌓여(-22px) 하나만 펼쳐져 있다. 접힌 카드를 누르면 그 카드가 펼쳐지고, 펼쳐진 카드를 한 번 더 누르면 목적 상세로 간다. |
| FPurposeDetail / Empty | 상태 `collapsed`, `menu`, `edit`, `add`, `sheet`(`pick`·`confirm`·`done`), `del`. **머리 접기**([값](motion.md#머리-접기-목적-상세아카이브-상세)): 목록을 조금이라도 위로 스크롤하면 위쪽 색 면이 접힌 띠 위치까지 부드럽게 스냅하고, 띠(뒤로·아이콘·이름·+·⋯)가 페이드·슬라이드로 나타난다(220ms). 펼친 머리 쪽으로 조금이라도 내리면 맨 위로 스냅해 다시 펼쳐진다. 손잡이를 누르면 두 상태가 바뀐다. 실제 앱에서는 손잡이 끌기와 목록 스크롤 모두로 전환한다. |
| FPurposeEditInPlace | 상태 `edit`, `color`, `icon`, `dirty`, `discard`. ⋯ → 편집. 접힌 상태였다면 머리가 먼저 펼쳐진다(부드러운 스크롤). 후보 추가·비교 끝내기 줄이 접히고 색·아이콘 고르기 면과 취소·저장이 펼쳐지며, 그만큼 시트가 부드럽게 내려간다(260ms). 이름·설명 글자는 제자리이고 밑줄만 나타난다. 편집 중에도 목록 스크롤로 머리가 접힌다. |
| FPurposeAddCandidates / CategoryFilter | 상태 `add`, `fk`(`all`·`custom`), `ftop`·`fcat`, `catMode`, `railTop`, `sel`(고른 상품). 후보 추가 시트. 위 필터 칩(가로 스크롤)에서 `전체`·카테고리 선택을 바꾸면 목록이 바로 걸러진다. 카테고리 선택은 같은 시트 안이 레일+칩으로 바뀐다. 상품을 누르면 선택이 토글되고, 다른 목적에 속한 상품은 "옮겨져요" 표시가 붙는다. 버튼은 `n개 추가`(0개면 비활성). |
| FPurposeFinishPick → Confirm → Done | 상태 `sheet`(`pick` → `confirm` → `done`), `picked`(-1 = 구매하지 않았어요), `listOpen`. 비교 끝내기 시트가 같은 시트 안에서 단계가 바뀐다: 구매 상품 고르기(선택 사항, "구매하지 않았어요") → 확인(함께 아카이브할 후보 펼치기, 뒤로) → 완료. |
| FPurposeDeleteConfirm | 상태 `del`, `delList`. ⋯ → 삭제. 목적 미지정이 될 후보 목록을 펼쳐 볼 수 있다. |

### 상품

| 화면 | 동작 |
| --- | --- |
| FProductDetail → Edit | 상태 `edit`, `purpose`·`cat`(저장된 값), `draft`·`draftCat`(편집 중 값), `sheet`(목적 시트), `catSheet`·`create`·`catTop`(카테고리 시트), `menu`, `del`, `dirty`, `discard`. 목록의 상품 카드를 누르면 카드 사진이 상세 사진 자리로 커지며 상세가 열린다. 보기 화면에서 편집을 누르면 같은 화면이 편집 상태가 된다(글자 위치 그대로, 밑줄과 취소·저장만 나타남). 목적·카테고리 줄을 누르면 각각 선택 시트가 열리고, 고르면 바로 닫히며 편집 중 값만 바뀐다. 저장해야 반영된다. 목적 시트에는 `목적 연결 해제`가 있다. |
| FProductCategoryPicker / Create | 레일+칩 시트. `+ 카테고리`를 누르면 같은 시트가 `신규 카테고리` 폼으로 바뀌고, 뒤로 돌아갈 수 있다. |
| FProductFill / FillEdit | 같은 상태에서 `purpose`·`cat`이 비어(`null`) 시작한다. 정보가 부족한 상품은 빈 칸이 강조된 상태로 열리고, 누르면 같은 화면이 편집 상태가 된다. |
| FProductProcessing | 상태 `menu`, `del`, `help`. 분석 중 상품. ⋯에는 삭제만 있고, 삭제 확인창의 `?`를 누르면 도움말 한 줄이 펼쳐진다. |

| FArchiveList | 기록 카드를 누르면 카드 면이 자리 표시로 떠올라 상세로 커진다. 머리는 sticky. |

### 로그인 · 설정 · 공유 수신 · 웹뷰

| 화면 | 동작 |
| --- | --- |
| FSettings | 상태 `logged`, `out`(로그아웃 확인), `wv`(웹뷰 데이터 삭제 확인), `wvDone`. 줄을 누르면 줄 면이 자리 표시로 떠올라 다음 화면으로 커진다. 로그아웃(먹색 확인), 웹뷰 데이터 삭제(빨강 확인) 확인창. 삭제 뒤 보조 줄이 "방금 삭제했어요"로 바뀐다. 로그아웃하면 로그인 전 설정으로 바뀐다. |
| FShareSaved* | 상태 없음. [모션](motion.md#6-공유-저장-카드). 원래 앱 위에 저장 확인 카드가 아래에서 올라와(340ms) 버튼 없이 1.5초 보인 뒤 아래로 내려가며(260ms) 닫힌다. |
| FWebView | 상태 `hist`·`fwd`(뒤로·앞으로 가능 수), `sheet`(공유 시트), `ext`(외부 앱 확인). 뒤로·앞으로 버튼은 기록이 있을 때만 활성. 공유 버튼은 공유 시트를 연다. |
| FWebViewExternal | 쇼핑몰 페이지가 외부 앱을 열려고 하면 확인창(정보 아이콘 상태 색 `external`)을 띄우고, 사용자가 `열기`를 눌러야 연다. |

## 탭과 화면 스택

- 하단 탭은 홈·카테고리·목적 세 개다. 탭 전환은 [페이드 스루](motion.md#3-탭-전환-페이드-스루)이고, 각 탭은 스크롤 위치와 하위 화면 스택을 따로 기억한다.
- 탭 바는 탭 첫 화면과 목록 화면(세부 유형 목록, 끝난 비교 목록)에서 보인다. 상세, 연속 처리, 설정, 웹뷰처럼 탭 바가 없는 화면으로 가면 다음 화면 내용과 함께 사라진다.
- 화면 사이 이동은 모두 [공유 요소 전환](motion.md#2-화면-이동-pushpop)이다. 이동 대상은 각 보드의 `href`와 [보드 목록](../screens/README.md#보드-목록)의 "이동 대상" 열에 있다.
